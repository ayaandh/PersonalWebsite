Writing a Programming Language

I recently wrote my own interpreted programming language in C++ and it was a pleasant (not really) experience. Ever since I started programming I wanted to make my own language and write an OS in it. Unfortunately I have only accomplished a fraction of that dream. Since my language is interpreted it can't exactly write a OS since writing an OS needs Assembly (I don't know assembly yet) and a language that can talk to assembly (mine can't) and compile it's code to machine code (mine can't).

But my language can do lots of other things too. but thats not what I am here to talk about today. I'm here to talk about how was the experience of writing a Language. One thing I have to advise all others who are writing a language is don't treat project architecture like its nothing. If you do you'll find it gets pretty messy as your language growsa. I personally only started with 4 C++ files and 3 header files. later when I needed to expand I split up my files which required some re-writes and took alot of time from development. So start proejct architecture early and you'll not regret it later.

Anothing thing I need to address is at times you'd feel like giving up and trust me don't. Giving up never did anyone any good. If the early Computer Scientists gave up then we wouldn't be here would be. So do not give up on you code even if your code gives up on you.
