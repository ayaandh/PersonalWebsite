## Hosting

Upload the contents of this folder to the root of your static website hosting. The pages use root-relative paths such as `/projects/`, so the site is intended to be hosted at the root of a domain.

Open `index.html` locally for a basic preview. For correct navigation between subpages, use a local static server or deploy to static hosting.
